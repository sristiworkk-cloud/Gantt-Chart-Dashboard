# Client Onboarding Project Using Excel

## Overview
An Excel tool that plans client onboarding in one sheet. It shows who is doing what, when each task starts and ends, and how far along it is.

## Project Objective
To make onboarding a new client clear and repeatable, so no step is missed and every deadline is visible.

## Key Features
- **Task Management:** Onboarding work is split into 3 phases (Planning, Execution, Review) with 12 tasks.
- **Timeline Visualization:** A Gantt chart draws each task as a bar across a 25-week timeline.
- **Progress Tracking:** The bar fills as you update the completion percentage.
- **Current Week Highlight:** The week the project is in is marked automatically.
- **Task Ownership:** Every task has a named owner.
- **Duration Calculation:** Excel formulas work out task duration and weeks in progress.

## Tools and Techniques
- Microsoft Excel
- Excel Formulas (date calculations, `ROUNDUP`, `IF`)
- Conditional Formatting
- Data Bars
- Gantt Chart Visualization
